# PNG to Icon — Documentation

`png-to-icon` turns **PNG images into a Windows icon file (`.ico`)**, the
file a Windows program puts in its resource script
(`IDI_APP ICON "app.ico"`) or ships next to a shortcut. It is both:

- **a command line tool**, `png-to-icon`, run by hand or from build
  scripts;
- **a C++ static library**, `png-to-icon.application`, the same tool as a
  class (`XYO::PNGToICON::Application`) that another program can run
  without starting a process.

The image work itself is done by
[xyo-pixel32](https://github.com/g-stefan/xyo-pixel32)
(`XYO::Pixel32::Process::pngToIcon`); `png-to-icon` is the command line
front end for it.

```
png-to-icon app.png app.ico
```

```
app.ico  16 x 16, 24 x 24, 32 x 32, 48 x 48   32 bit color + 1 bit mask each
```

## Why it exists

Every Windows executable of the XYO stack carries an icon. The artwork is
drawn once, as a PNG with transparency; Windows wants an `.ico` with
several sizes, each one a bitmap plus a transparency mask.
`png-to-icon` does the conversion with no image editor and no external
dependency, so it can run in a build:

| Problem | What `png-to-icon` does |
|---------|-------------------------|
| Windows picks the icon size by context (taskbar, Explorer, title bar) | writes 16, 24, 32 and 48 pixel images in one `.ico` |
| Only one drawing exists | resizes one PNG to all four sizes |
| Small sizes need hand drawn pixels | `--list` takes one PNG per size (`app-16.png`, `app-24.png`, ...) |
| Other sizes are needed (64, 128, 256) | `--list-x 16,32,64,256` takes any set of sizes, each PNG used at its own size |
| Modern Windows uses alpha, old renderers use a 1 bit mask | every image is 32 bit with the PNG's smooth alpha **and** a 1 bit mask, cut at `--level` |
| Transparent pixels show a color in renderers that ignore alpha | `--background RRGGBB` gives fully transparent pixels that color |

## Concepts at a glance

| Need | Command line | Library (`xyo-pixel32`) |
|------|--------------|--------------------------|
| One PNG → 16, 24, 32, 48 | `png-to-icon app.png app.ico` | `Process::pngToIcon("app.png", "app.ico", 48, false, 0)` |
| One PNG per size | `png-to-icon --list app app.ico` (reads `app-48.png`, `app-32.png`, `app-24.png`, `app-16.png`) | `Process::pngToIcon(png48, png32, png24, png16, "app.ico", 48, false, 0)` |
| Any sizes | `png-to-icon --list app --list-x 16,32,64,256 app.ico` | `Process::pngToIcon(fileList, "app.ico", 48, false, 0)` |
| Harder or softer mask edge | `--level 128` (alpha below 128 is transparent in the mask) | `level = 128` |
| Color of transparent pixels | `--background FFFFFF` | `useBackgroundAlpha = true, background = XYO_PIXEL32_PIXEL(255, 255, 255, 255)` |
| Run the tool from your own program | | `XYO::PNGToICON::Application` (`png-to-icon.application`) |
